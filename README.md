# video-largo-render
Renderer de videos largos (narración + escenas + sfx + música + look) con ffmpeg, para el workflow n8n "Video largo YouTube". Desplegado en Coolify (video.licjuanpablo.com.ar). v2: transiciones por escena (trans_in), subtítulos quemados (spec.subtitles), ducking configurable, sin pantallas negras por escenas fallidas. v4: modo proyecto (/projects, caché de assets y de tomas), FX visibles (scene.fx: punch, shake, glitch, flash, lower, title, stamp), transiciones más largas, referencias del juego gratis (/refs: Fandom + StrategyWiki).
