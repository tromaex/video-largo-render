# video-largo-render
Renderer de videos largos (narración + escenas + sfx + música + look) con ffmpeg, para el workflow n8n "Video largo YouTube". Desplegado en Coolify (video.licjuanpablo.com.ar). v2: transiciones por escena (trans_in), subtítulos quemados (spec.subtitles), ducking configurable, sin pantallas negras por escenas fallidas.
